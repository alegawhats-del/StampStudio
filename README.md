# Stamp Studio

Программа для Windows: печати и подписи на PDF в точных миллиметрах, сканирование, обрезка и разрезка страниц, «как скан», сжатие, ИИ-помощник.

## Установка

1. Откройте [последний релиз](https://github.com/alegawhats-del/StampStudio/releases/latest).
2. Скачайте установщик:
   - `StampStudio-Setup-x.y.z.exe` — основная версия;
   - `StampStudioCanon-Setup-x.y.z.exe` — версия для сканеров Canon.
3. Запустите его и нажимайте «Далее». Права администратора не нужны.

При первом запуске Windows может показать синее окно «Система Windows защитила ваш компьютер» — нажмите «Подробнее», затем «Выполнить в любом случае».

## Обновление

Программа сама проверяет новую версию при запуске. Если она есть — появится окно «Вышла версия …», кнопка «Обновить сейчас» скачает и поставит её, программа перезапустится. Проверить вручную — кнопка с номером версии в правом нижнем углу окна.

Печати и настройки лежат в папке `.stamp_studio` в профиле пользователя и при обновлении не трогаются.

## ИИ-помощник

Меню «ИИ»: имя файла по содержимому, печать и подпись на «М.П.», данные из документа в таблицу, проверка перед отправкой, распознавание текста скана. Работает через бесплатные сервисы (Google Gemini, NVIDIA NIM, Z.AI, Groq, Ollama Cloud); ключ вводится в «ИИ → Настройки ИИ и ключи». Распознавание текста по умолчанию делает сама Windows, без интернета.

Встроенные ключи для сборки задаются секретом репозитория `FREE_KEYS` (JSON `{"Google Gemini": "…", "Groq (быстро, бесплатно)": "…"}`); в репозиторий они не попадают — `tools/pack_keys.py` кладёт их в `keys.bin` только на сборочной машине.

## Справка

В программе: кнопка «Справка» или F1 — руководство с картинками. Картинки собирает `tools/make_guide.py` из настоящих окон программы (`docs/guide.json`, `docs/img/`).

## Сборка

Релизы собирает GitHub Actions (`.github/workflows/release.yml`) при пуше в `main`: если версии `APP_VERSION` ещё нет в релизах, собираются оба установщика, публикуется релиз и обновляется `version.json`. Текст «Что нового» берётся из `NOTES.md`.
